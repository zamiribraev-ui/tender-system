# 🤖 TenderAI — Система анализа тендеров Казахстана

Автоматически собирает тендеры с **goszakup.gov.kz** и **zakup.sk.kz**,
анализирует их через AI (Claude) и показывает клиентам рекомендации.

## 📁 Структура проекта

```
tender_system/
├── backend/
│   └── main.py          ← Сервер (парсер + AI + база данных)
├── frontend/
│   └── index.html       ← Веб-интерфейс
└── README.md
```

## 🚀 Установка и запуск

### 1. Установить зависимости Python

```bash
pip install requests anthropic
```

### 2. Получить API токены

**Anthropic (Claude AI):**
- Зайти на https://console.anthropic.com
- Создать API ключ
- Вставить в `backend/main.py` в строку `ANTHROPIC_API_KEY`

**Госзакуп API токен:**
- Зарегистрироваться на https://goszakup.gov.kz
- Зайти в раздел "Разработчикам" → "Открытые данные"
- Получить токен и вставить в `GOSZAKUP_API_TOKEN`

### 3. Запустить бэкенд

```bash
cd backend
python main.py
```

Сервер запустится на http://localhost:8000

### 4. Открыть интерфейс

Открыть файл `frontend/index.html` в браузере.

## 📋 Что умеет система

- ✅ Парсит тендеры с goszakup.gov.kz через GraphQL API
- ✅ Парсит тендеры с zakup.sk.kz (Самрук-Казына)
- ✅ Анализирует каждый тендер через Claude AI для каждого клиента
- ✅ Показывает рекомендацию: Участвовать / Нет / Рассмотреть
- ✅ Объясняет причины и риски
- ✅ Несколько клиентов с разными профилями
- ✅ Фильтрация по источнику и рекомендации
- ✅ Автоматическое обновление раз в день
